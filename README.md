# Dependency Graph Visualizer (Alpine apk)

Инструмент визуализации графа зависимостей для пакетов Alpine Linux (apk) без использования сторонних библиотек. Выполнен в рамках Практической работы №2 (Вариант №1).

## 1. Общее описание
Приложение выполняет:
- Сбор данных о зависимостях пакетов напрямую из репозитория Alpine Linux (`APKINDEX.tar.gz`).
- Построение транзитивного графа зависимостей и выявление циклов с помощью нерекурсивного обхода в глубину (DFS).
- Расчет топологического порядка загрузки зависимостей.
- Генерацию графа в формате Mermaid и сохранение в векторный формат SVG.
- Поддержку тестового режима с чтением структуры графа из текстового файла.

## 2. Описание функций и настроек
Параметры командной строки:
- `--package` (обязательный): Имя анализируемого пакета (например, `curl` или `A` в тестовом режиме).
- `--repo` (обязательный): URL-адрес репозитория Alpine или путь к файлу тестового графа.
- `--test-mode` (опциональный): Флаг включения тестового режима (чтение графа из файла).
- `--output` (обязательный): Путь к сохраняемому выходному файлу с расширением `.svg`.

Ключевые модули:
- `src/cli.py`: Парсинг аргументов командной строки и валидация конфигурации.
- `src/apk_parser.py`: Скачивание и потоковая распаковка `APKINDEX`, извлечение прямых зависимостей и виртуальных пакетов.
- `src/graph.py`: Нерекурсивный DFS на явном стеке, детекция циклов и расчет порядка загрузки.
- `src/visualizer.py`: Форматирование графа в Mermaid и запись валидного SVG-файла.
